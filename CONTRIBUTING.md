# Contribution Guide

Thank you for your interest in this project. If you want to help with development, fix bugs, or update code comments, your contributions are welcome.

# Getting Started 🛠️

* Fork this repository
* Make your changes
* Commit your work
* Submit a pull request with your changes

If you’re unsure about anything, open an issue to discuss it first.

### Pull Requests ⚙️

* Follow the existing code style
* Use tabs for indentation, not spaces
* Write all comments in English
